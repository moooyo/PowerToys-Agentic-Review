## Journeys

- [Review findings and prepare publication](flows/publication.svg): Read a saved outcome, deliberately select feedback, inspect the exact payload, and review a known result. All data is illustrative.
- [Inspect an approval blocker](flows/p0-guard.svg): Review a confirmed unresolved P0 from the complete original report; selection and filtering cannot bypass the guard.
- [Recover an interrupted investigation](flows/interrupted-resume.svg): Inspect the stop reason and retained state, review the budget, and follow a new attempt only after accepted recovery.
- [Move from issue assessment to linked work](flows/issue-followup.svg): Review a saved plan and exact source before requesting linked work; a child task is navigable only when returned by the server.
- [Recover an unconfirmed action outcome](flows/unknown-recovery.svg): Preserve the existing intent and distinguish status reads from permission-gated reconciliation. No new action is inferred.
- [Enter the workspace and recover an expired session](flows/auth.svg): Review the authentication gate, signed-in navigation, account controls, and identity boundaries without using real credentials.
- [Review repository settings, local drafts, and version conflicts](flows/repository-settings.svg): Trace repository configuration separately from all-repository scheduling and inspect the consequences of leaving or reloading a local draft.
- [Trace an event through investigation and publication activity](flows/activity-linkage.svg): Keep webhook handling, task execution, report content, and comment delivery as separate outcomes with explicit context links.
