# 内置账号密码系统

状态：已实现，并完成隔离远端回归与浏览器验收。用户要求本轮仅补齐本系统自己的账号密码，不接第三方身份服务。
PowerToys 专用 UI 场景和模型质量评估移出当前任务，不作为本功能的交付条件。

## 使用流程

部署者通过受控配置初始化第一个管理员。空账号库必须提供初始化信息，不能通过公开页面
抢先注册管理员，也不提供默认真实密码。后续启动读取已保存账号，初始化配置不会覆盖
已经修改过的密码、权限或账号状态。

未登录用户在控制台填写用户名和密码。登录成功后进入原先访问的工作页面；退出、会话过期、
账号禁用或授权变更后，受保护页面和缓存会被清除，重新登录才能继续访问。

普通用户可以修改自己的密码。管理员可以查看账号、创建账号、调整显示名称与权限、启用或
禁用账号，以及重置账号密码。重置或修改密码会撤销该账号全部会话，不返回或显示旧密码。
用户名作为稳定登录名，创建后不提供重命名。账号使用禁用状态，不删除历史操作的身份引用。

## 权限边界

`isAdmin` 仅授予账号管理能力。业务权限继续使用明确的仓库 ID、任务权限、操作能力和
仓库代码执行授权，管理员身份不会隐式获得所有仓库权限。

账号管理页面只对管理员展示，Server 独立重新检查权限。创建、更新或重置账号必须通过
受保护接口；更新和重置包含当前账号版本，避免覆盖其他管理员刚完成的修改。
在事务内保护最后一个启用的管理员，防止并发降权或禁用导致系统失去管理入口。

账号禁用、密码变更和权限变更都撤销已有会话。请求读取持久化账号状态，不仅依赖登录时的
权限快照。异步密码校验完成后重新检查账号版本，避免校验期间发生重置或禁用后仍签发会话。

本系统的登录凭据与 GitHub API token、Worker bearer token 分开管理。
取消第三方登录不会改变 GitHub 实际权限、当前 SHA、操作准备与确认等检查。

## 凭据与会话

- 用户名规范化为小写 ASCII，长度 3–64，可包含字母、数字、点、下划线和连字符，并以字母或数字开头。
- 新密码长度 15–128，按输入原样校验，不自动修剪空白或改变大小写；不接受完全由空白组成的密码。
- 使用带独立随机盐的密码哈希，不保存明文密码。密码校验采用异步、有界的计算资源。
- 错误用户名、错误密码、禁用账号使用统一的登录失败响应；不存在的账号仍执行等成本的密码验证。
- 登录和密码操作限流，避免无界密码计算。账号相关限流与连接来源限流分别考虑。
- 会话使用随机不透明 token，数据库仅保存 token 摘要；浏览器使用 HttpOnly Cookie。
- 远程访问要求 HTTPS；HTTP 仅用于真正的本机 loopback。保留 Host、Origin 和 Cookie 的同源限制。
- Cookie 会话有明确过期时间，退出会撤销服务端会话；日志和 API 响应不包含密码、密码哈希或可复用会话 token。

## API 与数据

共享契约位于 `packages/contracts/src/investigation-auth.ts`。

| API | 行为 |
| --- | --- |
| `GET /api/auth/session` | 返回登录状态、内置身份、有效权限和会话过期时间。 |
| `POST /api/auth/login` | 接收用户名、密码，校验后签发新会话。 |
| `POST /api/auth/logout` | 撤销会话并清除 Cookie。 |
| `POST /api/auth/password` | 校验当前密码，保存新密码并撤销本人全部会话。 |
| `GET /api/accounts` | 管理员查看不含凭据的账号列表。 |
| `POST /api/accounts` | 管理员创建账号及明确授权。 |
| `POST /api/accounts/:id/update` | 按版本更新状态、显示名称和权限。 |
| `POST /api/accounts/:id/password` | 管理员按版本重置密码并撤销目标账号会话。 |

公开账号包含身份、用户名、显示名称、管理员标记、启用状态、版本、时间和业务授权。
密码哈希和会话摘要只属于服务端私有存储。
正式认证仅使用 `password` 模式，不保留无密码登录旁路或第三方登录跳转。

使用新的独立账号数据库初始化 schema，不转换旧 OIDC/loopback 认证数据库。
Task/Report 业务数据库与账号数据库保持分离，已有报告及操作身份记录不因改密而改写。
离线管理员工具支持部署者在受控主机上恢复账号访问，工具不开放为未认证 HTTP 接口。

## 前端与示例

沿用当前 Material 界面，增加登录表单、账号管理页面和本人改密入口。
表单提供加载、失败、版本冲突和会话撤销状态；密码只保存在当前表单内存，操作结束即清除。

开发预览使用明确标注的合成账号和内存数据，登录、退出和账号操作可以完整体验。
示例凭据只属于开发预览；生产构建删除示例数据初始化，HTTP 失败时不回退到合成账号。
已有 PowerToys 示例报告保留，不会因账号演示而启动真实 Worker 或发送 GitHub 操作。

2. 正确与错误登录、大小写规范化、限流、同源检查、Cookie 和会话过期/退出。

4. 最后管理员保护，以及密码校验和账号更新之间的并发竞态。
